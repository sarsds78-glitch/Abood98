# IRAQ WAZ — Android starter v0.3.0

نسخة تطوير Android Native مبنية بـ Kotlin وJetpack Compose وMapLibre.

## الموجود في هذه النسخة
- واجهة عربية RTL لخريطة العراق، مع تمركز ابتدائي على الرمادي (مركز عرض افتراضي وليس موقع المستخدم).
- خريطة MapLibre عبر نمط العرض التجريبي `demotiles.maplibre.org`.
- طلب صلاحية الموقع الدقيق أو التقريبي واستخدام آخر موقع معروف عبر Fused Location Provider.
- البحث عن الأماكن عبر Android Geocoder (تعتمد النتائج على مزود Geocoder والاتصال المتاح على الجهاز).
- طلب مسار قيادة عبر خدمة OSRM التجريبية العامة، ورسم هندسة المسار على الخريطة، وعرض المسافة والمدة التقديرية.
- GitHub Actions workflow لبناء APK تجريبي ورفعه كـ Artifact.

## حدود مهمة
هذه نسخة MVP تقنية وليست إصداراً تجارياً مكتملاً. نمط الخريطة وخدمة OSRM هنا للتطوير والاختبار فقط؛ لا توجد ضمانة SLA أو صلاحية للاستخدام التجاري. لا توجد حالياً قاعدة مرور عراقية حية، أو إعادة توجيه تلقائية أثناء القيادة، أو صوت ملاحة turn-by-turn، أو خرائط offline. لا تعرض هذه النسخة معلومات المرور على أنها مباشرة.

قبل الإطلاق العام، استبدل مصادر التجربة بمزود خرائط/توجيه مستضاف أو مرخّص، أضف Backend موثوقاً، اختبر جودة شبكة الطرق العراقية ميدانياً، وأضف سياسة خصوصية ومراقبة وأمان.

## البناء محلياً
المتطلبات: JDK 17، Android SDK Platform 35، Android Build Tools 35، وGradle 8.11.1.

```bash
cd mobile/android
gradle --no-daemon assembleDebug
```

الناتج:
`mobile/android/app/build/outputs/apk/debug/app-debug.apk`

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. اجعل الفرع الافتراضي `main`.
3. افتح تبويب Actions.
4. شغّل `Build IRAQ WAZ Android APK` يدوياً من Run workflow أو ادفع تحديثاً إلى `main`.
5. افتح تشغيل workflow الناجح ثم نزّل Artifact باسم `iraq-waz-debug-apk`.

هذا ينتج Debug APK للتجربة، وليس APK إصداراً تجارياً موقّعاً بمفتاح نشر. لا تشارك مفاتيح توقيع Android داخل المستودع.

## مصادر البيانات
- OpenStreetMap/MapLibre: راجع نسب البيانات وشروط مزود tiles المستخدم قبل النشر.
- OSRM demo server: للاختبار فقط؛ لا تستخدمه كخدمة إنتاج عامة.
- Android Geocoder: النتائج تختلف باختلاف الجهاز ومزود الخدمة والبلد.
